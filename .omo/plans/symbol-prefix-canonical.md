# symbol-prefix-canonical - Work Plan

## TL;DR (For humans)

**What you'll get:** 修复 issue #181——股票代码统一使用带交易所前缀的完整格式（如 `SZ000001`、`SH600905`），中证 500 指数（SH000905）与厦门港务（SZ000905）不再混淆为同一个 000905，数据中不再出现同一天两行。全部代码、输入、配置只认带前缀的代码，裸 6 位码输入被禁止（旧配置自动迁移）。

**Why this approach:** 根因是 import 时把前缀剥掉（`SUBSTRING(symbol,3)`），导致 SH/SZ 同码碰撞。正本清源——import 不再剥前缀、全链路（数据/引擎/GUI/输入）统一使用前缀格式，前缀和代码永远在一起。

**What it will NOT do:** 不清洗 Dolt 源数据、不排除指数、不去重、不引入新依赖、不动休眠的 baostock 代码与 Python 采集器、不改 GUI 外观。修复后需重新跑 import 才能让本地数据生效。

**Effort:** XL（五 crate 全改 + ~40 处测试更新）
**Risk:** High - 跨五 crate 的格式变更，覆盖全链路输入/存储/消费；最大风险点已由 Metis 提前锁定（SEPA BJ 停牌过滤的 exchange 派生、parquet.rs exchange 列查询、默认值裸码）

**Decisions to sanity-check:** 输入层全面禁止裸码（D9，含 CLI/GUI/config）、旧 config 自动迁移（D10）、GUI 搜索框保持自由文本但提交值必须前缀（D11）、stock_basic 删除 exchange 列（D6）。

Your next move: 已获批准。执行前可运行 high-accuracy review（momus + Oracle 双审），或直接用 `$start-work symbol-prefix-canonical` 开始执行。Full execution detail follows below.
