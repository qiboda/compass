# 图表应用（GUI）

## 启动

```sh
scripts/run.sh      # 一键启动（前台运行，Ctrl+C 退出）
cargo run --bin compass   # 等价的手动方式
```

应用打开一个 **1440×900** 的暗色主题窗口，标题为 "Compass — Stock Chart"。
字体全部内嵌：中文使用思源黑体（Source Han Sans CN，Regular + Bold），
价格/代码/时间等数字使用 JetBrains Mono（等宽对齐）。

## 界面布局（三栏式专业终端）

```
┌─ 工具栏 (40px)：[标的] 可搜索选择器  [周期] 1d|1w|1M  [操作] Fetch  [显示] 侧边栏切换 · 主题 ┐
├──────────┬──────────────────────────────────────────────────────────────────────────┤
│ 侧边栏    │  DockArea（图表 | 日志 | 选股器 三个标签页，可拖拽调整）                      │
│ 240px     │                                                                          │
│ 自选股     │                                                                          │
└──────────┴──────────────────────────────────────────────────────────────────────────┘
┌─ 状态栏 (26px)：标的摘要（mono 价格+涨跌） │ 加载/错误状态 │ 本地数据源 · N 只 · 时钟 ──┐
```

### 工具栏（逻辑分组）

| 分组 | 控件 | 用途 |
|---|---|---|
| 标的 | 可搜索输入框 | 输入代码前缀（如 `600`）或名称子串（如 `平安`）过滤股票列表，弹窗列出匹配项 |
| 周期 | 分段选择器 `1d \| 1w \| 1M` | 控制 OHLCV 柱的聚合 |
| 操作 | **Fetch**（Primary 主按钮，loading 时禁用+spinner） | 从本地数据库加载所选股票的图表数据 |
| 显示 | 侧边栏切换按钮 + 主题下拉 | 显隐左侧自选栏 / 在 `compass_dark` 与 `compass_light` 之间切换 |

### 侧边栏（自选股）

- 顶部搜索框（过滤自选）＋ **＋** 添加按钮：把当前标的加入自选（去重 + 排序）。
- 「自选」分组列出 watchlist 中的股票（名称 + mono 代码 + 交易所标签），
  当前标的行带左侧 accent 竖条；行点击 → 切换图表并触发 Fetch。
- 行 hover 显示 **×** 删除按钮 → 弹出 **Danger 确认 Modal**（「移除」/「保留」），
  确认后从自选移除并持久化。
- 自选股持久化到 `~/.config/compass/config.toml` 的 `[watchlist]` 节（见
  [配置](config.md)），重启后恢复。
- 自选为空时显示空态引导（「自选股为空 / 点击 + 添加关注的股票」）。

### 状态栏

三段式：左段当前标的摘要（mono 价格 + 涨跌幅，红涨绿跌）；中段状态
（加载中…/错误文案）；右段数据源信息（`本地数据源 · N 只`）+ 本地时钟（每秒刷新）。

### 吐司通知

状态反馈以临时吐司通知形式显示，锚定在窗口**右上角**。每条吐司显示一个
Phosphor 图标字形、简短消息，并在预设时长后自动消失。

| 类型 | 图标 | 消失时间 | 示例 |
|---|---|---|---|
| **Loading** | ⏳ | —（保持到加载完成） | 正在从本地数据库加载数据 |
| **Success** | ✅ | 3 秒 | "Data loaded: sh.600519 (100 bars)" |
| **Warning** | ⚠ | 3 秒 | "No data available for this date range" |
| **Error** | ❌ | 8 秒 | "Network error: connection timeout" |
| **Info** | ℹ | 3 秒 | "Import complete: 2,430 records" |

吐司垂直堆叠；最多同时显示 10 条，超出时最旧的先消失。

### 图表区域

- 未加载任何数据时显示**空态引导**（「暂无图表数据 / 输入代码并点击 Fetch」）。
- K 线柱支持：**平移**（点击水平拖拽）、**缩放**（滚轮）、**十字准线**（hover 查看
  OHLCV 详情）、可见柱数默认 100。
- **日期中文**（ref #219）：x 轴刻度紧凑式（`1月`/`5月15日`/`2024`），十字光标与
  tooltip 完整式（`2024年5月15日`）；tooltip 标签全中文（`时间:`/`开盘:`/`最高:`/
  `最低:`/`收盘:`/`成交量:`/`涨跌:`）。
- **周期切换立即重载**（ref #218）：切换 1d/1w/1M（点击或快捷键 1/2/3）后图表
  立即重新加载，无需手动点 Fetch；启动时选中的周期与配置 `default_timeframe` 一致。
- **MA/BOLL 叠加**（ref #174）：K 线上叠加 MA(5/10/60/120/250) 均线与 BOLL(20,2)
  布林带，指标实时计算、不存储，随主题切换换色（8 色暗/亮两套）。图表左上第二行
  为**指标图例行**（半透明 chip）：显示最后一根可见 bar 的 MA/BOLL 值，暖机期
  显示 `—`。
- **前复权**（ref #176）：K 线价格均为**前复权价**（最新一日与现价一致），工具栏
  「周期」组内显示「前复权」Tag 提示；本迭代无复权模式切换开关。

### SEPA 评分面板（东方SEPA）

**东方SEPA** 标签页（与图表共享顶部区域双 tab）展示全市场 TOP50 评分排名：

- 自上而下：**市场温度计**（评分 + 仓位建议 + 指标 chips）→ **工具条**（`共 N 行 · 日期`
  计数 + TOP 50/30 切换 + **刷新**按钮）→ **12 列排名表** + 右侧**详情面板**。
- **刷新**为手动触发（计算全市场约 1 分钟），loading 显示 spinner；无自动计算。
- 排名表格列：排名 / 代码 / 名称 / 总分 / 趋势 / 题材 / 资金 / 形态 / 风险 / 行业 /
  最新价 / 涨跌幅；默认按排名升序，点击表头切换列与升降序。
- **点击任意行** → 图表立即切换到该股票（K 线加载），右侧详情面板显示评分明细
  （五模块得分条 + 子项 + 题材标签）。
- 行点击需先**激活详情**：首次点击行即加载详情，后续点击切换标的。
- **TOP N 切换**仅影响显示行数，切换回 50 数据不丢。
- 排名表格布局修复（ref #221）：表格始终显示在表头**下方**（而非右侧），
  详情面板固定在表格右侧。

### 日志

可滚动的日志面板（egui_lens）显示获取状态、错误和 citizen 生命周期事件。
面板头新增**导出按钮**：点击打开保存文件对话框，把日志条目写入文本文件
（`[时间戳] [级别] 消息`），成功/失败以 toast 反馈。

### 选股器（Screener）

**Screener** 标签页提供条件选股：按元数据与技术面条件筛选全市场 A 股。
条件表单分为两张卡片：**基础条件**（行业/交易所/板块多选、上市时长、市值区间、
排除退市）与**技术面条件**（均线/突破新高/动量/量能，各自带启用开关与参数）。

| 条件 | 说明 |
|---|---|
| 行业 | 可搜索多选（输入过滤 + 勾选 + 完成） |
| 交易所 | SH / SZ / BJ 多选 |
| 板块 | 主板 / 创业板 / 科创板 / 北交所 多选（数据驱动） |
| 上市时长 | 不限 / ≥1年 / ≥3年 / ≥5年 |
| 市值区间 | min/max（亿元） |
| 均线 | 启用开关 + 关系：站上 MA20 / 站上 MA60 / 多头排列 MA5>MA20>MA60 |
| 突破 | 启用开关 + N 日新高（默认 60，上限 250） |
| 动量 | 启用开关 + N 日（默认 20，上限 250）+ min%/max% |
| 量能 | 启用开关 + N 日（默认 20，上限 80）+ 倍数（默认 2.0） |
| 排除退市 | 默认勾选 |

多条件之间全部 **AND**；行业/交易所/板块内多值 **OR**。技术指标全部基于
**前复权（adjclose）** 计算。

**交互**：
- 每个条件的**标签与选择控件同行**（原子组布局，ref #220）——窄窗口下面板
  变窄时整组下移换行，组内标签与控件永不拆行。
- 多选/下拉弹层（行业/交易所/板块/上市时长）可**同时打开多个**且互不遮挡
  （每个弹层独立 id，ref #220）。
- 点击 **筛选** 手动触发；每次全量重读、无缓存。执行期间显示 loading spinner。
- 结果表格 6 列：代码 / 名称 / 最新价 / 20日涨跌幅 / 市值(亿) / 行业。
  最新价与 20日涨跌幅按**红涨绿跌**着色（mono 字体）；点击表头切换列与升降序
  （内存排序，默认按代码升序）。市值缺失（total_share 为 NULL）显示 `0`。
- 最多显示 100 行。
- 点击任意结果行 → 图表立即切换到该股票（K 线加载），工具栏股票选择器同步。
- 空条件 = 全市场非退市股票按代码升序前 100。
- 条件持久化到 `~/.config/compass/config.toml` 的 `[screener]` 节（每次点筛选
  时保存），重启后恢复。结果不持久化。

**已知限制**：基本面/估值条件与 MACD 属第二版（需先补 `fin_indicators.parquet`
导出）。

### 主题切换

| 预设 | 描述 |
|---|---|
| `compass_dark` | 默认暗色主题（TradingView 风格） |
| `compass_light` | 亮色主题，适合白天使用 |

工具栏 **🎨** 下拉切换，即时应用于所有 UI 元素；切换成功弹出 Info toast。
当前主题持久化到 `~/.config/compass/config.toml` 的 `theme` 键（顶层），下次启动恢复。

### 模态对话框（Modal）— 三个真实场景

| 场景 | 触发 | 内容 |
|---|---|---|
| 数据未就绪引导 | 启动时本地找不到 `stock_basic.parquet`（股票列表为空） | 说明数据缺失原因 + 导入命令提示 +「知道了」按钮 |
| 日志导出 | 日志面板点导出按钮 | 系统保存文件对话框（egui-file-dialog） |
| 移除自选确认 | 侧边栏行 hover 点 × | Danger 样式确认框：「移除」/「保留」 |

## 数据流程

点击 "Fetch" 时：

1. 搜索框接受自由文本（裸码/前缀/名称均可输入，D11），选中/提交时规范化为带前缀形式（如 `SZ000001`）
2. **查询本地 Parquet** — `DuckDbProvider` 通过 DuckDB 的 `read_parquet()` 直接读取 `stock_daily.parquet`
3. **显示图表** — 柱状数据以 K 线形态呈现

GUI 是**仅限本地**的：它从不调用东方财富或任何在线 API。所有数据来自本地 Parquet
主数据库。如果某只股票不在数据库中，GUI 显示 "no data" 消息 — 需先用数据管线
（`compass-data import` 或 Python 采集器）导入数据。

## 股票代码

从下拉框中选择或输入搜索：

| 代码 | 股票 | 交易所 |
|---|---|---|
| `000001` | 平安银行 | SZ |
| `600519` | 贵州茅台 | SH |
| `688001` | 华兴源创 | SH |
| `300750` | 宁德时代 | SZ |
| `830799` | 艾融软件 | BJ |

上表是**显示层视图**（展示豁免，D5）——列表/图例按 `代码 + 交易所` 分列展示；
存储、提交与数据访问仍使用带前缀的规范符号（如 `SZ000001`）。

交易所选择（SH/SZ/BJ）作为搜索过滤条件；提交给数据层的股票代码
一律为带前缀形式（如 `SZ000001`）——裸码提交被拒绝（D9）。自选股存
带前缀的代码。

## 配置默认值

创建 `~/.config/compass/config.toml` 来设置启动偏好：

```toml
theme = "compass_light"

[app]
default_symbol = "SH600519"
default_timeframe = "1d"

[watchlist]
symbols = ["SH600519", "SZ000002"]
```

全部选项见 [配置](config.md)。

## 数据前置条件

图表应用通过 DuckDB 的 `read_parquet()` 直接从 `parquet_data/stock_daily.parquet`
读取 OHLCV 数据（内存模式，无需持久化 DuckDB 文件）。首次使用前，请确保数据已就绪：

```sh
# 从 Dolt 导入（完整历史）
cargo run --bin compass-data -- import
# 数据已就绪 — parquet_data/stock_daily.parquet 是数据源
```

如果某只股票不在本地数据库中，GUI 显示 "no data" 消息 — 无在线回退。请先导入缺失的数据。

要使股票下拉框有数据，`stock_basic.parquet` 必须存在于 parquet 数据目录中
（默认：`parquet_data/`）。该文件由 `import-compass --table stock_basic` 创建；
缺失时启动会弹出「数据未就绪」引导 Modal。
