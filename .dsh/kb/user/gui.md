# 图表应用（GUI）

## 启动

```sh
just                # 一键启动（默认 recipe，前台运行，Ctrl+C 退出）
scripts/run.sh      # 备用入口（无 just 环境）
cargo run --bin compass   # 等价的手动方式
```

应用打开一个 **1440×900** 的暗色主题窗口，标题为 "Compass — Stock Chart"。
字体全部内嵌：中文使用思源黑体（Source Han Sans CN，Regular + Bold），
价格/代码/时间等数字使用 JetBrains Mono（等宽对齐）。

## 界面布局（Blender 式 Workspace 编辑器架构）

```
┌─ Topbar (40px)：[图表|选股|SEPA 复盘]  [标的选择器 ▾]  [⋮ 添加编辑器]  [主题] [语言] ┐
├──────────────────────────────────────────────────────────────────────────────────┤
│  内容区：当前 Workspace 的 dock 树（egui_dock，可拖拽/关/开 tab；布局自动保存）        │
├──────────────────────────────────────────────────────────────────────────────────┤
│ 状态栏 (26px)：标的摘要（mono 价格+涨跌） │ 加载/错误状态 │ 本地数据源 · N 只 · 时钟 ──┐
```

每个 **Workspace**（工作区）是一个任务域：图表 / 选股 / SEPA 复盘，顶部
Topbar 左侧 **三段 Segmented** 切换。每个 workspace 内是若干**编辑器**
（Editor）——图表（Chart）/ 自选股（Watchlist）/ 选股器（Screener）/
东方SEPA / 大盘 / 日志（Logger），以 dock 树组织（可拖动分隔条、关/开 tab）。
**切换 workspace 或拖动/关闭 tab 时布局即时写入配置**（见「布局持久化」），
重启后恢复；编辑器内部状态（图表缓存、选股条件、SEPA 数据）跨切换保留。

### Topbar（顶部栏）

| 分组 | 控件 | 用途 |
|---|---|---|
| 左 | workspace 三段切换 `[图表\|选股\|SEPA 复盘]`（图标 + 名称） | 切换整个工作区布局；切换即时保存到配置，重启恢复 |
| 中 | 标的选择器（可搜索输入框） | 输入代码前缀（如 `600`）或名称子串（如 `平安`）过滤股票列表，弹窗列出匹配项 |
| 右 | `⋮` 添加编辑器（图标按钮下拉） | 列出当前 workspace 中**未在屏**的编辑器，点击重新打开已关闭的 tab |
| 最右 | 主题下拉 + 语言下拉 | 在 `compass_dark` 与 `compass_light` 之间切换 / 在 中文 与 English 之间切换 |

周期 / 复权 / Fetch 等**图表专属控件已移入「图表」编辑器自己的 header**
（见下「图表」小节），Topbar 不再显示——它们只在图表 workspace 的图表编辑器
中出现，避免在无图表语境显示无效控件。

### 自选股（Watchlist 编辑器）

自选股已从旧「全局左栏」升级为独立编辑器——位于**图表 workspace 左侧的 dock
leaf tab**（可与其它编辑器拖动重排/关闭，宽度随分隔条拖拽，无固定值；不响应
N 键——它没有侧栏）。关闭后经 Topbar `⋮` 添加编辑器重开。

- 顶部搜索框（过滤自选）＋ **＋** 添加按钮：把当前标的加入自选（去重 + 排序）。
  `Ctrl+K` 聚焦该搜索框。
- 「自选」分组列出 watchlist 中的股票（名称 + mono 代码 + 交易所标签），
  当前标的行带左侧 accent 竖条；行点击 → 切换图表并触发 Fetch。
- 行 hover 显示 **×** 删除按钮 → 弹出 **Danger 确认 Modal**（「移除」/「保留」），
  确认后从自选移除并持久化。
- 自选股持久化到 `~/.config/compass/config.toml` 的 `[watchlist]` 节（见
  [配置](config.md)），重启后恢复。
- 自选为空时显示空态引导（「自选股为空 / 点击 + 添加关注的股票」）。

### 状态栏

三段式：左段当前标的摘要（mono 价格 + 涨跌幅，红涨绿跌）；中段状态
（加载中…/错误文案）；右段数据源信息（`本地数据源 · N 只`）+ 本地时钟（每秒刷新）。

### 吐司通知

状态反馈以临时吐司通知形式显示，锚定在窗口**右上角**。每条吐司显示一个
Phosphor 图标字形、简短消息，并在预设时长后自动消失。

| 类型 | 图标 | 消失时间 | 示例 |
|---|---|---|---|
| **Loading** | ⏳ | —（保持到加载完成） | 正在从本地数据库加载数据 |
| **Success** | ✅ | 3 秒 | "Data loaded: sh.600519 (100 bars)" |
| **Warning** | ⚠ | 3 秒 | "No data available for this date range" |
| **Error** | ❌ | 8 秒 | "Network error: connection timeout" |
| **Info** | ℹ | 3 秒 | "Import complete: 2,430 records" |

吐司垂直堆叠；最多同时显示 10 条，超出时最旧的先消失。

### 图表（Chart）

图表编辑器有自己的 **header**（顶部条，替代旧全局工具栏里的图表控件）：
左侧 **周期** `1d|1w|1M` + **复权**下拉（指数/板块时隐藏）→ **指标**下拉
（MA/BOLL 显隐开关）→ 右端 **Fetch** 按钮 + **`⋮` 显示选项**菜单（十字准线/
交易量/图例开关 + **侧栏**切换项，与 N 键同功能）。
图表编辑器还有**右侧侧栏**（N 键或 `⋮` 菜单切换显示，默认显示）：
**指标参数**（MA 周期编辑、BOLL 参数）+ **图层设置**（K 线样式、成交量子开关）。

- 未加载任何数据时显示**空态引导**（「暂无图表数据 / 输入代码并点击获取数据」）。
- K 线柱支持：**平移**（点击水平拖拽）、**缩放**（滚轮）、**十字准线**（hover 查看
  OHLCV 详情）、可见柱数默认 100。
- **日期格式**（ref #219，键化 ref #222）：zh 下日期显示中文——x 轴刻度紧凑式
  （`1月`/`5月15日`/`2024`），十字光标与 tooltip 完整式（`2024年5月15日`）；
  tooltip 标签随语言（zh `时间:`/`开盘:`/`最高:`/`最低:`/`收盘:`/`成交量:`/
  `涨跌:`，en `Time:`/`Open:`/`High:`/`Low:`/`Close:`/`Volume:`/`Change:`）。
  切到 en 后日期与标签自动切换为英文短格式。
- **周期切换立即重载**（ref #218）：切换 1d/1w/1M（点击周期分段或快捷键 1/2/3）
  后图表立即重新加载，无需手动点 Fetch；启动时选中的周期与配置
  `default_timeframe` 一致。**快捷键 1/2/3 仅在图表 workspace 生效**
  （选股/SEPA 复盘下无效）。
- **MA/BOLL 叠加**（ref #174）：K 线上叠加 MA(5/10/60/120/250) 均线与 BOLL(20,2)
  布林带，指标实时计算、不存储，随主题切换换色（8 色暗/亮两套）。图表左上第二行
  为**指标图例行**（半透明 chip）：显示最后一根可见 bar 的 MA/BOLL 值，暖机期
  显示 `—`。
- **复权方式切换**（ref #345）：图表 header 周期分段旁下拉三档——**前复权/后复权/不复权**
  （默认前复权，`config` 的 `default_adjust` 可改）。前复权最新一日与现价一致；
  切换立即重载 K 线（与周期切换一致），会话内不持久化；指数/板块（无复权概念）
  隐藏该控件；SEPA 面板「最新价」始终为不复权现实价（close），不受切换影响。

### 大盘面板（Market）

**大盘** 编辑器（位于 **SEPA 复盘 workspace**，与东方SEPA 同叶两 tab 互切）
展示指数/板块市场概览，打开即读快照（与 SEPA 同构）：

- 自上而下：**核心指数 Card**（官方指数核心白名单 6 只：上证指数/深证成指/
  创业板指/沪深300/中证500/中证1000，名称 + mono 点位 + 涨跌幅，hover 高亮）
  → **header**（`共 N 个 · 日期` 计数 + `[行业板块|官方指数]` 分段切换 +
  **刷新**按钮 + 右端 `⋮` 菜单：**重置排序**——恢复默认涨幅降序）
  → **板块/指数排序表**（名称 / 代码 / 最新 / 涨跌幅 / 成交额，默认按涨跌幅降序）。
- **行业板块为默认段**（概念段已随 issue #283 移除）；分段切换只过滤本地内存副本，
  不重新查询。
- 点击 Card 或任意列表行 → 图表立即加载该指数/板块 K 线，**不切 tab**（图表 workspace）。
- 指数复权控件隐藏（指数无复权）；刷新为手动触发，无自动刷新。
- 空态：「暂无指数数据」（`index_daily.parquet` 缺失时）。

### SEPA 评分面板（东方SEPA）

**东方SEPA** 编辑器（位于 **SEPA 复盘 workspace**，与大盘同叶两 tab 互切）
展示全市场 TOP50 评分排名：

- 自上而下：**市场温度计**（评分 + 仓位建议 + 指标 chips）→ **header**
  （`共 N 行 · 日期` 计数 + TOP 50/30 切换 + **刷新**按钮 + 右端 `⋮` 菜单：
  **重置排序**——恢复官方默认排序）→ **12 列排名表** + 右侧**详情面板**。
- **刷新**为手动触发（计算全市场约 1 分钟），loading 显示 spinner；无自动计算。
- 排名表格列：排名 / 代码 / 名称 / 总分 / 趋势 / 题材 / 资金 / 形态 / 风险 / 行业 /
  最新价 / 涨跌幅；默认按排名升序，点击表头切换列与升降序。数值列与表头右对齐
  （ref #217 验收）；涨跌幅列显示单一带符号百分比（如 `+2.50%`，红涨绿跌）。
  **表头点击排序会持久生效**——用乱了想恢复官方顺序，点 header 右端 `⋮` →
  重置排序即可（幂等动作）。
- **点击任意行** → 图表 workspace 的图表立即切换到该股票（K 线加载），右侧详情
  面板显示评分明细（五模块得分条 + 子项）。题材模块（issue #283 D5）基于
  **行业板块**聚合评分（stock_basic.industry 分组），不再有概念主题标签。
- 行点击需先**激活详情**：首次点击行即加载详情，后续点击切换标的。
- **TOP N 切换**仅影响显示行数，切换回 50 数据不丢。
- 排名表格布局修复（ref #221）：表格始终显示在表头**下方**（而非右侧），
  详情面板固定在表格右侧（约 280px，位于编辑器 body 内——**不是侧栏**，不响应
  N 键）；超宽内容横向滚动（ref #217 验收）。
### 日志（Logger）

可滚动的日志编辑器（egui_lens），**位于三个 workspace 的底部 leaf**，显示获取
状态、错误和运行事件；可拖动重排/关闭（关闭后经 Topbar `⋮` 添加编辑器重开）。
header 为 `[日志] · N 条` 左侧 + **导出按钮**右侧：点击打开保存文件对话框，
把日志条目写入文本文件（`[时间戳] [级别] 消息`），成功/失败以 toast 反馈。

### 选股器（Screener）

**Screener** 编辑器（选股 workspace 主编辑器）提供条件选股：用**条件卡片组**
按元数据与技术面条件筛选全市场 A 股。构建器采用 Metabase 范式：每张卡片一个
条件，卡片可分组为 **且 (AND)** / **或 (OR)** 并任意嵌套（至少 2 层），替换了
旧版固定表单。

**编辑器的 sidebar（右侧，N 键或 header `⋮` 菜单切换，默认显示，约 500px 宽）**
即条件构建器；底部有 **运行 / 清空** 按钮。header 左侧显示计数「共 N 只」
与运行中状态 chip，右端 `⋮` 菜单含 **重置排序**（恢复默认市值降序）与
**清除结果**。

**条件卡片**：组底「添加条件」菜单选择类型 → 卡片插入组尾，参数就地编辑。

| 条件卡 | 说明 |
|---|---|
| 行业 | 可搜索多选（输入过滤 + 勾选 + 完成） |
| 交易所 | SH / SZ / BJ 多选 |
| 板块 | 主板 / 创业板 / 科创板 / 北交所 多选（数据驱动） |
| 上市时长 | 不限 / ≥1年 / ≥3年 / ≥5年 |
| 市值区间 | min/max（亿元） |
| 排除退市 | 勾选即条件生效，取消勾选删除卡片（默认勾选） |
| 均线 | 关系：站上 MA20 / 站上 MA60 / 多头排列 MA5>MA20>MA60 |
| 突破 | N 日新高（默认 60，上限 250） |
| 动量 | N 日（默认 20，上限 250）+ min%/max% |
| 量能 | N 日（默认 20，上限 80）+ 倍数（默认 2.0） |
| 连续上涨 | N 天（通达信 UPNDAY 风格）+ min% |

**分组与嵌套**：组头 Segmented 切换 且 (AND) / 或 (OR)；添加菜单选
「子分组」插入空组（默认 AND），组内继续添加卡片或再嵌套。默认根组预置
6 张基础卡（行业/交易所/板块/上市时长/市值/排除退市），与旧版默认行为一致。

**交互**：
- 卡片行的**标签与选择控件同行**（原子组布局，ref #220）——窄窗口下面板
  变窄时整组下移换行，组内标签与控件永不拆行。
- 多选/下拉弹层（行业/交易所/板块/上市时长/添加菜单）可**同时打开多个**
  且互不遮挡（每个弹层独立 id，ref #220）。
- 删除卡片/清空条件**无确认**（条件可轻易重建）；卡片头「取反」开关将条件
  包裹为 Not（排除语义）。
- 点击 sidebar 底部 **运行** 手动触发；每次全量重读、无缓存。执行期间显示 loading spinner。
- 结果表格 6 列：代码 / 名称 / 最新价 / 20日涨跌幅 / 市值(亿) / 行业。
  最新价与 20日涨跌幅按**红涨绿跌**着色（mono 字体）；点击表头切换列与升降序
  （内存排序，**默认按市值降序**，并列按代码升序——与表头点击排序持久生效一致，
  用乱了点 `⋮` → 重置排序）。市值缺失（total_share 为 NULL）显示 `0`。
- 最多显示 100 行。
- 点击任意结果行 → 图表立即切换到该股票（K 线加载），Topbar 标的选择器同步。
- 空条件 = 全市场非退市股票按默认市值降序前 100。
- 条件持久化到 `~/.config/compass/config.toml` 的 `[screener]` 节（每次点筛选
  时以 Filter AST JSON 保存——任意组合含或组/连续上涨均可保存），重启后恢复。
  结果不持久化。

**AI 自然语言生成（LLM）**：配置了 `[llm]` API key 时，条件卡组**顶部**
（Screener 侧栏内）显示自然语言输入框 +「AI 生成」按钮（epic #243 Batch 4，ref #247）。输入如
「最近连续5天每天涨超3%、市值大于100亿」→ LLM 返回 Filter AST JSON →
经类型与语义校验后以**条件卡片**并入当前卡组（可编辑/删除/持久化，与手动
卡片完全同构）。未配置 key 时入口整体隐藏；生成失败（网络/无法解析/包含
构建器暂不支持的条件类型，如窗口计数）在输入区下方显示内联错误 + 右上角
提示，输入文本保留可改后重试。生成中按钮禁用 + spinner，按 Esc 可取消
在途请求。

（如 上证指数 → SSE Composite、白酒 → Baijiu；概念板块已随 #283 移除，

## 布局持久化（`[layout]`）

工作区布局（各 workspace 的 dock 树、active workspace）持久化到
`~/.config/compass/config.toml` 的 **`[layout]` 节**：

```toml
[layout]
active_workspace = "chart"   # "chart" | "screener" | "sepa"
dock_version = 2

[[layout.workspaces]]        # 每 workspace 一条；实际写盘为内联数组形状，
id = "chart"                 # 两种形状读回均兼容
active_screen = 0
dock = """{"root":{"split":{...}}}"""   # 布局拓扑 JSON（split 方向+比例+各 leaf 的编辑器序列）
```

- **保存时机**：切换 workspace、拖动分隔条、移动/关闭 tab 时**即时写盘**——
  无需退出/手动保存；重启后恢复上次的工作区与布局。
- **损坏回退**：配置损坏不会阻止启动——`dock_version` 不匹配/结构损坏时回退
  **整套三默认布局**；仅个别条目损坏（拓扑 JSON 坏、缺 dock 条目等）时**只回退
  对应 workspace** 的默认布局，其余定制布局保留（warn 日志，`RUST_LOG=debug`
  可观察）。
- **不持久化**：编辑器内部状态（图表周期/复权、自选股侧栏显隐等）为会话级，
  重启后回到默认；选股条件另有 `[screener]` 节持久化，自选股列表另有
  `[watchlist]` 节持久化（见[配置](config.md)）。

## 数据流程

点击 "Fetch" 时：

1. 搜索框接受自由文本（裸码/前缀/名称均可输入，D11），选中/提交时规范化为带前缀形式（如 `SZ000001`）
2. **查询本地 Parquet** — `DuckDbProvider` 通过 DuckDB 的 `read_parquet()` 直接读取 `stock_daily.parquet`
3. **显示图表** — 柱状数据以 K 线形态呈现

GUI 是**仅限本地**的：它从不调用东方财富或任何在线 API。所有数据来自本地 Parquet
主数据库。如果某只股票不在数据库中，GUI 显示 "no data" 消息 — 需先用数据管线
（`compass-data import` 或 Rust 采集器 `compass-collectors`）导入数据。

## 数据前置条件

图表应用通过 DuckDB 的 `read_parquet()` 直接从 `parquet_data/stock_daily.parquet`
读取 OHLCV 数据（内存模式，无需持久化 DuckDB 文件）。首次使用前，请确保数据已就绪：

```sh
# 从 Dolt 导入（完整历史）
cargo run --bin compass-data -- import
# 数据已就绪 — parquet_data/stock_daily.parquet 是数据源
```

如果某只股票不在本地数据库中，GUI 显示 "no data" 消息 — 无在线回退。请先导入缺失的数据。

要使股票下拉框有数据，`stock_basic.parquet` 必须存在于 parquet 数据目录中
（默认：`parquet_data/`）。该文件由 `import-compass --table stock_basic` 创建；
缺失时启动会弹出「数据未就绪」引导 Modal。
下拉列表只显示**当前上市 A 股**（`delist_date` 为空）：已退市股票与 B 股被过滤（ref #71）——
`stock_basic` 表本身按设计包含退市股与 B 股，GUI 在加载时过滤。
