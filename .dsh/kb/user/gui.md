# 图表应用（GUI）

## 启动

```sh
just                # 一键启动（默认 recipe，前台运行，Ctrl+C 退出）
scripts/run.sh      # 备用入口（无 just 环境）
cargo run --bin compass   # 等价的手动方式
```

应用打开一个 **1440×900** 的暗色主题窗口，标题为 "Compass — Stock Chart"。
字体全部内嵌：中文使用思源黑体（Source Han Sans CN，Regular + Bold），
价格/代码/时间等数字使用 JetBrains Mono（等宽对齐）。

## 界面布局（三栏式专业终端）

```

├──────────┬──────────────────────────────────────────────────────────────────────────┤
│ 侧边栏    │  DockArea（egui_dock，可拖拽/关/开 tab）                                    │
│ 240px     │  ┌────────────────────────────────────────────────────────────────────┐  │
│ 自选股     │  │ 顶部 leaf：[图表] [大盘] [东方SEPA] 三个 tab（共享全宽，逐一切换）          │  │
│           │  ├── (split_below 0.75) ──────────────────────────────────────────────┤  │
│           │  │ [日志]                                                              │  │
│           │  ├── (split_below 0.5) ───────────────────────────────────────────────┤  │
│           │  │ [选股器]                                                            │  │
```

### 工具栏（逻辑分组）

| 分组 | 控件 | 用途 |
|---|---|---|
| 标的 | 可搜索输入框 | 输入代码前缀（如 `600`）或名称子串（如 `平安`）过滤股票列表，弹窗列出匹配项 |
| 周期 | 分段选择器 `1d \| 1w \| 1M` | 控制 OHLCV 柱的聚合 |
| 操作 | **Fetch**（Primary 主按钮，loading 时禁用+spinner） | 从本地数据库加载所选股票的图表数据；按钮文案随界面语言（zh「获取数据」/ en "Fetch"） |
| 显示 | 侧边栏切换按钮 + 主题下拉 + 语言下拉 | 显隐左侧自选栏 / 在 `compass_dark` 与 `compass_light` 之间切换 / 在 中文 与 English 之间切换 |

### 侧边栏（自选股）

- 顶部搜索框（过滤自选）＋ **＋** 添加按钮：把当前标的加入自选（去重 + 排序）。
- 「自选」分组列出 watchlist 中的股票（名称 + mono 代码 + 交易所标签），
  当前标的行带左侧 accent 竖条；行点击 → 切换图表并触发 Fetch。
- 行 hover 显示 **×** 删除按钮 → 弹出 **Danger 确认 Modal**（「移除」/「保留」），
  确认后从自选移除并持久化。
- 自选股持久化到 `~/.config/compass/config.toml` 的 `[watchlist]` 节（见
  [配置](config.md)），重启后恢复。
- 自选为空时显示空态引导（「自选股为空 / 点击 + 添加关注的股票」）。

### 状态栏

三段式：左段当前标的摘要（mono 价格 + 涨跌幅，红涨绿跌）；中段状态
（加载中…/错误文案）；右段数据源信息（`本地数据源 · N 只`）+ 本地时钟（每秒刷新）。

### 吐司通知

状态反馈以临时吐司通知形式显示，锚定在窗口**右上角**。每条吐司显示一个
Phosphor 图标字形、简短消息，并在预设时长后自动消失。

| 类型 | 图标 | 消失时间 | 示例 |
|---|---|---|---|
| **Loading** | ⏳ | —（保持到加载完成） | 正在从本地数据库加载数据 |
| **Success** | ✅ | 3 秒 | "Data loaded: sh.600519 (100 bars)" |
| **Warning** | ⚠ | 3 秒 | "No data available for this date range" |
| **Error** | ❌ | 8 秒 | "Network error: connection timeout" |
| **Info** | ℹ | 3 秒 | "Import complete: 2,430 records" |

吐司垂直堆叠；最多同时显示 10 条，超出时最旧的先消失。

### 图表（Chart）

- 未加载任何数据时显示**空态引导**（「暂无图表数据 / 输入代码并点击获取数据」）。
- K 线柱支持：**平移**（点击水平拖拽）、**缩放**（滚轮）、**十字准线**（hover 查看
  OHLCV 详情）、可见柱数默认 100。
- **日期格式**（ref #219，键化 ref #222）：zh 下日期显示中文——x 轴刻度紧凑式
  （`1月`/`5月15日`/`2024`），十字光标与 tooltip 完整式（`2024年5月15日`）；
  tooltip 标签随语言（zh `时间:`/`开盘:`/`最高:`/`最低:`/`收盘:`/`成交量:`/
  `涨跌:`，en `Time:`/`Open:`/`High:`/`Low:`/`Close:`/`Volume:`/`Change:`）。
  切到 en 后日期与标签自动切换为英文短格式。
- **周期切换立即重载**（ref #218）：切换 1d/1w/1M（点击或快捷键 1/2/3）后图表
  立即重新加载，无需手动点 Fetch；启动时选中的周期与配置 `default_timeframe` 一致。
- **MA/BOLL 叠加**（ref #174）：K 线上叠加 MA(5/10/60/120/250) 均线与 BOLL(20,2)
  布林带，指标实时计算、不存储，随主题切换换色（8 色暗/亮两套）。图表左上第二行
  为**指标图例行**（半透明 chip）：显示最后一根可见 bar 的 MA/BOLL 值，暖机期
  显示 `—`。
- **前复权**（ref #176）：K 线价格均为**前复权价**（最新一日与现价一致），工具栏
  「周期」组内显示「前复权」Tag 提示；本迭代无复权模式切换开关。

### 大盘面板（Market）

**大盘** 标签页（与图表、东方SEPA 共享顶部 leaf 三 tab）展示指数/板块市场
概览，打开即读快照（与 SEPA 同构）：

- 自上而下：**核心指数 Card**（官方指数核心白名单 6 只：上证指数/深证成指/
  创业板指/沪深300/中证500/中证1000，名称 + mono 点位 + 涨跌幅，hover 高亮）
  → **工具条**（`共 N 个 · 日期` 计数 + `[行业板块|官方指数]` 分段切换 + **刷新**按钮）
  → **板块/指数排序表**（名称 / 代码 / 最新 / 涨跌幅 / 成交额，默认按涨跌幅降序）。
- **行业板块为默认段**（概念段已随 issue #283 移除）；分段切换只过滤本地内存副本，
  不重新查询。
- 点击 Card 或任意列表行 → 图表立即加载该指数/板块 K 线，**不切 tab**。
- 指数前复权 Tag 隐藏（指数无复权）；刷新为手动触发，无自动刷新。
- 空态：「暂无指数数据」（`index_daily.parquet` 缺失时）。

### SEPA 评分面板（东方SEPA）

**东方SEPA** 标签页（与图表共享顶部区域双 tab）展示全市场 TOP50 评分排名：

- 自上而下：**市场温度计**（评分 + 仓位建议 + 指标 chips）→ **工具条**（`共 N 行 · 日期`
  计数 + TOP 50/30 切换 + **刷新**按钮）→ **12 列排名表** + 右侧**详情面板**。
- **刷新**为手动触发（计算全市场约 1 分钟），loading 显示 spinner；无自动计算。
- 排名表格列：排名 / 代码 / 名称 / 总分 / 趋势 / 题材 / 资金 / 形态 / 风险 / 行业 /
  最新价 / 涨跌幅；默认按排名升序，点击表头切换列与升降序。数值列与表头右对齐
  （ref #217 验收）；涨跌幅列显示单一带符号百分比（如 `+2.50%`，红涨绿跌）。
- **点击任意行** → 图表立即切换到该股票（K 线加载），右侧详情面板显示评分明细
  （五模块得分条 + 子项）。题材模块（issue #283 D5）基于**行业板块**聚合评分
  （stock_basic.industry 分组），不再有概念主题标签。
- 行点击需先**激活详情**：首次点击行即加载详情，后续点击切换标的。
- **TOP N 切换**仅影响显示行数，切换回 50 数据不丢。
- 排名表格布局修复（ref #221）：表格始终显示在表头**下方**（而非右侧），
  详情面板固定在表格右侧；超宽内容横向滚动（ref #217 验收）。
### 日志

可滚动的日志面板（egui_lens）显示获取状态、错误和 citizen 生命周期事件。
面板头新增**导出按钮**：点击打开保存文件对话框，把日志条目写入文本文件
（`[时间戳] [级别] 消息`），成功/失败以 toast 反馈。

### 选股器（Screener）

**Screener** 标签页提供条件选股：用**条件卡片组**按元数据与技术面条件筛选
全市场 A 股。构建器采用 Metabase 范式：每张卡片一个条件，卡片可分组为
**且 (AND)** / **或 (OR)** 并任意嵌套（至少 2 层），替换了旧版固定表单。

**条件卡片**：组底「添加条件」菜单选择类型 → 卡片插入组尾，参数就地编辑。

| 条件卡 | 说明 |
|---|---|
| 行业 | 可搜索多选（输入过滤 + 勾选 + 完成） |
| 交易所 | SH / SZ / BJ 多选 |
| 板块 | 主板 / 创业板 / 科创板 / 北交所 多选（数据驱动） |
| 上市时长 | 不限 / ≥1年 / ≥3年 / ≥5年 |
| 市值区间 | min/max（亿元） |
| 排除退市 | 勾选即条件生效，取消勾选删除卡片（默认勾选） |
| 均线 | 关系：站上 MA20 / 站上 MA60 / 多头排列 MA5>MA20>MA60 |
| 突破 | N 日新高（默认 60，上限 250） |
| 动量 | N 日（默认 20，上限 250）+ min%/max% |
| 量能 | N 日（默认 20，上限 80）+ 倍数（默认 2.0） |
| 连续上涨 | N 天（通达信 UPNDAY 风格）+ min% |

**分组与嵌套**：组头 Segmented 切换 且 (AND) / 或 (OR)；添加菜单选
「子分组」插入空组（默认 AND），组内继续添加卡片或再嵌套。默认根组预置
6 张基础卡（行业/交易所/板块/上市时长/市值/排除退市），与旧版默认行为一致。

**交互**：
- 卡片行的**标签与选择控件同行**（原子组布局，ref #220）——窄窗口下面板
  变窄时整组下移换行，组内标签与控件永不拆行。
- 多选/下拉弹层（行业/交易所/板块/上市时长/添加菜单）可**同时打开多个**
  且互不遮挡（每个弹层独立 id，ref #220）。
- 删除卡片/清空条件**无确认**（条件可轻易重建）；卡片头「取反」开关将条件
  包裹为 Not（排除语义）。
- 点击 **筛选** 手动触发；每次全量重读、无缓存。执行期间显示 loading spinner。
- 结果表格 6 列：代码 / 名称 / 最新价 / 20日涨跌幅 / 市值(亿) / 行业。
  最新价与 20日涨跌幅按**红涨绿跌**着色（mono 字体）；点击表头切换列与升降序
  （内存排序，默认按代码升序）。市值缺失（total_share 为 NULL）显示 `0`。
- 最多显示 100 行。
- 点击任意结果行 → 图表立即切换到该股票（K 线加载），工具栏股票选择器同步。
- 空条件 = 全市场非退市股票按代码升序前 100。
- 条件持久化到 `~/.config/compass/config.toml` 的 `[screener]` 节（每次点筛选
  时以 Filter AST JSON 保存——任意组合含或组/连续上涨均可保存），重启后恢复。
  结果不持久化。

**AI 自然语言生成（LLM）**：配置了 `[llm]` API key 时，条件卡组顶部显示
自然语言输入框 +「AI 生成」按钮（epic #243 Batch 4，ref #247）。输入如
「最近连续5天每天涨超3%、市值大于100亿」→ LLM 返回 Filter AST JSON →
经类型与语义校验后以**条件卡片**并入当前卡组（可编辑/删除/持久化，与手动
卡片完全同构）。未配置 key 时入口整体隐藏；生成失败（网络/无法解析/包含
构建器暂不支持的条件类型，如窗口计数）在输入区下方显示内联错误 + 右上角
提示，输入文本保留可改后重试。生成中按钮禁用 + spinner，按 Esc 可取消
在途请求。

**已知限制**：基本面/估值条件与 MACD 属第二版（需先补 `fin_indicators.parquet`
导出）。

### 主题切换

| 预设 | 描述 |
|---|---|
| `compass_dark` | 默认暗色主题（TradingView 风格） |
| `compass_light` | 亮色主题，适合白天使用 |

工具栏 **🎨** 下拉切换，即时应用于所有 UI 元素（含按钮文字颜色，ref #217 验收）；
切换成功弹出 Info toast。

### 语言切换

工具栏「显示」组最右侧是**语言下拉**（选项为母语原生名：`中文` / `English`）。
切换**立即生效**：所有面板文案、按钮、图表 tooltip 与日期格式随 locale 一起切换
（zh 中文 / en 英文，如 Fetch 按钮 zh「获取数据」/ en "Fetch"），无需重启。
窗口标题保持英文品牌 **"Compass — Stock Chart"**（两种语言下均不变）。

**数据名称随语言切换（epic #266）**：指数、行业名在英文界面显示英文
（如 上证指数 → SSE Composite、白酒 → Baijiu；概念板块已随 #283 移除，
仅保留官方指数 + 行业板块两类）；
无英文译名的名称回退中文。**股票名不翻译**（任何语言下均显示中文，如 贵州茅台）。
**搜索三路匹配**：输入英文名也能找到对应指数/板块（如 "SSE" 找到上证指数、
"Moutai" 不会命中股票——股票名不参与英文搜索）；股票搜索仍按代码/中文名匹配。

选择会**自动写回** `~/.config/compass/config.toml` 的顶层 `language` 键
（`"zh"` 或 `"en"`），重启后保留上次的选择。配置文件里写 `language = "en"`
也可直接以英文启动；无效值回退 `zh`。默认 `zh`（见[配置](config.md)）。

## 数据流程

点击 "Fetch" 时：

1. 搜索框接受自由文本（裸码/前缀/名称均可输入，D11），选中/提交时规范化为带前缀形式（如 `SZ000001`）
2. **查询本地 Parquet** — `DuckDbProvider` 通过 DuckDB 的 `read_parquet()` 直接读取 `stock_daily.parquet`
3. **显示图表** — 柱状数据以 K 线形态呈现

GUI 是**仅限本地**的：它从不调用东方财富或任何在线 API。所有数据来自本地 Parquet
主数据库。如果某只股票不在数据库中，GUI 显示 "no data" 消息 — 需先用数据管线
（`compass-data import` 或 Rust 采集器 `compass-collectors`）导入数据。

## 数据前置条件

图表应用通过 DuckDB 的 `read_parquet()` 直接从 `parquet_data/stock_daily.parquet`
读取 OHLCV 数据（内存模式，无需持久化 DuckDB 文件）。首次使用前，请确保数据已就绪：

```sh
# 从 Dolt 导入（完整历史）
cargo run --bin compass-data -- import
# 数据已就绪 — parquet_data/stock_daily.parquet 是数据源
```

如果某只股票不在本地数据库中，GUI 显示 "no data" 消息 — 无在线回退。请先导入缺失的数据。

要使股票下拉框有数据，`stock_basic.parquet` 必须存在于 parquet 数据目录中
（默认：`parquet_data/`）。该文件由 `import-compass --table stock_basic` 创建；
缺失时启动会弹出「数据未就绪」引导 Modal。
下拉列表只显示**当前上市 A 股**（`delist_date` 为空）：已退市股票与 B 股被过滤（ref #71）——
`stock_basic` 表本身按设计包含退市股与 B 股，GUI 在加载时过滤。
