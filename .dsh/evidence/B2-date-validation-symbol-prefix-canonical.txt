B2 — --start-date/--end-date SQL injection closure (ref #181)
==============================================================
Finding (security review): crates/compass-data/src/import_dolt.rs match
(start_date, end_date) interpolates CLI values raw into the WHERE clause
("tradedate >= '{s}' AND tradedate <= '{e}'") with NO format validation,
unlike --since which requires exactly 8 ASCII digits. Vectors: quote
injection ("20200101' OR '1'='1" -> OR binds looser than AND -> full-range
export) and comment truncation ("20200101' --").

    got '{value}'"

    where_parts match arm (--since validation untouched; --symbols untouched)
